CAFE NEUROTICO: CREMA - User Manual

CAFE NEUROTICO: CREMA

1. OVERVIEW

THE SWEET FOAM ON TOP

Crema is the reddish-brown frothy foam on top of a freshly brewed espresso — a sign of freshness and proper pressure. If CNGM is the espresso machine, CREMA is the beautiful result you actually drink.

CREMA is CNGM’s fullscreen companion app — laidback, easygoing, and focused purely on fun. Designed for couch play with a gamepad, it presents your library in a bold, beautiful TV-mode interface with an integrated music player. Grab a controller and enjoy.

Launching CREMA

Place CREMA.AppImage (any capitalization) in the same folder as CNGM.AppImage. A Go Fullscreen With CREMA button appears at the bottom of CNGM’s sidebar. Clicking it minimizes CNGM and launches CREMA as a separate fullscreen process. CREMA can also be launched independently from your desktop launcher or terminal.

Shared Library

CNGM and CREMA access the exact same game_library.db database. Any game you add, scrape, or edit in CNGM is immediately visible in CREMA. Steam install status updates are pushed live to both apps simultaneously via a background file watcher — no manual refresh needed.

Recommendation: Do your heavy lifting in CNGM (syncing stores, bulk scraping, editing metadata). CNGM is built for mouse and keyboard; CREMA is built for a gamepad. Let each do what it does best.

Available Categories

  • All Games, Installed — full library or just what’s installed
  • Steam, GOG, Epic, Amazon — by store
  • Others, Physical, Emulation, Apps — manual categories
  • Want to Play, Favs — your personal curation lists

The On-Screen Keyboard (OSK)

A full-featured on-screen keyboard used for search, launch commands, playlist names, SGDB API key entry, and more. Navigate with D-pad or arrow keys. Confirm characters with A / Enter. Backspace, Clear, and Done keys are on the keyboard. Press B or Escape to cancel without saving.

3. GALLERY & GAMEPAGE

The Gallery

CREMA’s main view is a fullscreen cover-art grid. Categories scroll at the top — navigate with LB/RB (gamepad) or Left/Right arrows. Each card shows the cover and an install status indicator.

The Gamepage

Select a game and press A / Enter to open its Gamepage:

  • Hero Banner: Cinematic, takes up ~40% of screen height. Transparent Logo overlaid at center.
  • Stats Panel: Release Year, HLTB, ProtonDB, Genre, Co-op, Players, Metacritic.
  • Description: Short summary of the game.
  • Screenshots: Animated Ken Burns slideshow. Confirm to enter fullscreen; confirm again to advance frames.
  • Play / Install Button: Launches the game. Uninstalled store games show Install. Manual categories without a command open the OSK to add one.
  • Trailer Button: Appears only if a trailer was downloaded in CNGM. BGM fades out automatically while the trailer plays.

FAV & Want to Play

From the Gamepage menu, toggle Favorites and Want to Play. Changes write instantly to the shared database and are visible in CNGM immediately.

4. THE JUKEBOX

CREMA features a fully-integrated music player. Access it from System Menu → Audio → Jukebox.

Adding Custom Music

Place your audio files (MP3, WAV, OGG, FLAC) into the CREMA_CUSTOM_MUSIC folder located in the same directory as the app. Close and reopen the Jukebox for CREMA to scan the ID3 metadata (Title, Artist, Album, cover art) of your files.

Browsing Your Collection

  • Shuffle All: Randomized playback across your entire collection.
  • Artists: Browse your library organized by artist.
  • Albums: Browse organized by album.
  • Playlists: Create and manage custom playlists. Use the OSK to name them. Select any song or album to add it directly to a playlist.

Jukebox Features

  • Now Playing widget with cover art, title, and artist.
  • Queue management with Up Next display.
  • Search: Use the OSK to filter your library by title, artist, or album.
  • Fullscreen mode: Immersive animated fullscreen player view.
  • Background playback: Music continues playing while you browse your games. Use L3 / R3 on your gamepad to skip or rewind tracks without opening the menu.

5. SCREENSAVER & SLEEP MODE

The Screensaver

If you step away, CREMA triggers its dynamic screensaver after a configurable delay. Set it in System Menu → Appearance → Screensaver.

Delay options: 1, 2, 3, 4, 5, 10, 15, or 30 minutes (default: 3 min). Mode options:

  • CN Wallpapers (Default): A cinematic Ken Burns showcase of the curated Cafe Neurotico wallpaper collection, featuring N3UR0T1C the Hacker and Crema the Bon Vivant.
  • Screenshots: Slowly pans and zooms across high-res gameplay screenshots from your own library. While active, you can press a button to instantly launch the displayed game or toggle its Favorite / Want to Play status — without leaving the screensaver.
  • Off: Screensaver disabled entirely.

Sleep Mode & Waking Up

When you launch a game, CREMA fades to black and enters Sleep Mode, yielding all system resources to your game. The screen shows the game cover art, title, and wake-up instructions.

Once you close the game, wake CREMA using your configured combo. Default is START + SELECT simultaneously, which brings CREMA back to the front and restores background music. Configure this in System Menu → Controls → Wake Method.

Wake Method Options

  • START + SELECT (press)
  • L1 + R1 + START + SELECT (press)
  • L3 + R3 (press)
  • START + SELECT (hold 2 sec)
  • L1 + R1 + START + SELECT (hold 2 sec)
  • L3 + R3 (hold 2 sec)

Keyboard alternative: Holding comma (,) + period (.) simultaneously always wakes CREMA from both screensaver and sleep mode, regardless of which wake method is configured.

6. SCRAPING & METADATA

CREMA can scrape metadata for individual games. The scope matches CNGM’s Auto-Fetch: Cover, Hero Art, Logo, HLTB, ProtonDB, Description, Genre, Developer, Publisher, Co-op, Players, Metacritic, Screenshots.

How to Scrape

Navigate to a game in the gallery and press X / Square to open the scraping options (or use the Game Menu). CREMA will:

  1. Search Steam for the game by name. If found, proceed with a full Steam + IGDB scrape.
  2. If Steam search finds nothing, CREMA offers an IGDB fallback — a search overlay where you can type the correct game name using the OSK and select from results.
  3. You can also select Refine Search at any point to type a more precise title via the OSK and retry.

IGDB Fallback

When the Steam search fails, a search overlay appears with results from IGDB. Select the correct entry and CREMA fetches all available metadata. Especially useful for older games, non-English titles, or games not on Steam.

IGDB credentials required: The IGDB fallback requires a Twitch dev API key configured in CNGM’s Connect menu. Without it, only Steam-based scraping is available.

7. SOUND & SETTINGS

Press Start (gamepad) or M (keyboard) anywhere to open the System Menu. It is organized into sections:

Audio

  • Jukebox: Opens the full music player.
  • Sound Settings: Music style (BGM category), BGM on/off, SFX on/off, volume slider (0–100%, increments of 5%).

BGM Categories

If you don’t want to use the custom music folder, CREMA ships with built-in looping background tracks. Choose between:

  • Ambient (default) — atmospheric, relaxed
  • Lo-Fi — lo-fi chill beats
  • Jazz — laid-back jazz improvisations
  • Piano — classical piano
  • Custom — plays your CREMA_CUSTOM_MUSIC folder
  • Off — no background music

Appearance

  • Color Scheme: Switch between all available themes live — changes apply instantly.
  • Start Screen: Choose between Static (list), Carousel, or Grid layout.
  • Browse Mode: List or Gallery view.
  • Screensaver: Mode and delay configuration.

Themes are organised into categories. Use the dropdown on this page to preview them all:

  • Originals & System — CREMA (default), Dark Gray, Cyberpunk, Snow, MoviesFlix, Vapour OS, PSIV Blue, Green Box, Win XP.
  • Aesthetics — Earthy & Organic, Dopamine Brights, Retro Revival, Vaporwave, Aurora, Noir, Bioluminescence, Brutalist.
  • Linux Ricing — Dracula, Gruvbox, Nord, Solarized Dark/Light, all four Catppuccin flavours, Tokyo Night, Everforest, Rosé Pine, Oxocarbon, Material Dark.
  • Sci-Fi Universes — themed after iconic sci-fi worlds: N7, Tron Legacy, Dead Space, Colony Ship, Necromorph.
  • Horror Realm — dark and unsettling atmospheres: Crimson Peak, Lakeside Curse, The Backrooms.
  • Gaming Legends — Game Boy DMG, Pip-Boy, Sevastopol, Rip and Tear Classic, Super Brothers, Green Hill, NES, SNES.
  • PSIII Colors — seven monochrome PSIII palette variants: Classic, Red, Green, Blue, Purple, Gold, Silver.

Controls

  • Keybindings: View all gamepad and keyboard mappings.
  • Gamepad Icons: Switch displayed button icons between Xbox, PlayStation, and Nintendo layouts.
  • Wake Method: Configure the combo used to wake CREMA after a game closes.

Library

  • History: Configure how many recently played games pin to the top of the gallery (Off, 5, 9, or 18). Clear history to reset all timestamps.

System

  • Language: English or Português (BR).
  • About: Version info.
  • Quit: Exit CREMA.
