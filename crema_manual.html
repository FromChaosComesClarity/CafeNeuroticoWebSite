CAFE NEUROTICO: CREMA - User Manual

CAFE NEUROTICO: CREMA

1. OVERVIEW

THE SWEET FOAM ON TOP

Crema is the reddish-brown frothy foam on top of a freshly brewed espresso — a sign of freshness and proper pressure. If CNGM is the espresso machine, CREMA is the beautiful result you actually drink.

CREMA is CNGM’s fullscreen companion app — laidback, easygoing, and focused purely on fun. Designed for couch play with a gamepad, it presents your library in a bold, beautiful TV-mode interface with ambient music integration. Grab a controller and enjoy.

Launching CREMA

Place CREMA.AppImage (any capitalization) in the same folder as CNGM.AppImage. A Go Fullscreen With CREMA button appears at the bottom of CNGM’s sidebar. Clicking it minimizes CNGM and launches CREMA as a separate fullscreen process.

CREMA can also be launched independently from your desktop launcher or terminal — it always reads from the shared GameManagerConfig/game_library.db.

Shared Library

CNGM and CREMA access the exact same SQLite database. Any game you add, scrape, or edit in CNGM is immediately visible in CREMA. Steam install status updates are pushed live to both apps simultaneously via a background file watcher — no manual refresh needed.

Recommendation: Do your heavy-lifting in CNGM (syncing stores, bulk scraping, editing metadata). CNGM is built for mouse and keyboard; CREMA is built for a gamepad. Let each do what it does best.

Available Categories

  • All Games, Installed — full library or just what’s installed
  • Steam, GOG, Epic, Amazon — by store
  • Others, Physical, Emulation, Apps — manual categories
  • Want to Play, Favs — your personal curation lists

CREMA is designed around a unified gamepad mapping. Keyboard is also fully supported.

The On-Screen Keyboard (OSK)

For Physical, Emulation, Others, or Apps games without a launch command, pressing Play opens the OSK so you can type the command with your gamepad or keyboard. Navigate with the D-pad, confirm characters with A / Enter, cancel with B or Escape.

Wake from screensaver: Hold comma (,) and period (.) simultaneously on the keyboard to wake CREMA from its idle screensaver mode.

3. GALLERY & GAMEPAGE

The Gallery

CREMA’s main view is a fullscreen cover-art grid. Categories are shown at the top — navigate with LB/RB (gamepad) or Left/Right arrow keys. Each card shows the cover and an install status indicator. The grid reloads instantly for the selected category.

The Gamepage

Select a game and press A / Enter to open its Gamepage:

  • Hero Banner — cinematic, takes up ~40% of screen height. The transparent Logo is overlaid at center.
  • Stats Panel — Release Year, HLTB, ProtonDB, Genre, Co-op, Players, Metacritic.
  • Description — a short summary of the game.
  • Screenshots — animated Ken Burns slideshow. Confirm to enter fullscreen; confirm again to advance frames.
  • Play / Install Button — launches the game. Uninstalled store games show Install. Manual categories without a command open the OSK.
  • Trailer Button — appears only if a trailer was downloaded in CNGM. BGM fades out automatically when playing.

FAV & Want to Play

From the Gamepage menu, toggle Favorites and Want to Play. Changes write instantly to the shared database and are reflected in CNGM immediately.

Installed Status

Each gallery card has a small status indicator. Games with a launch command / confirmed as installed show as active. For Physical, Others, Emulation, or Apps games without a command, pressing Play or the Install button opens the OSK to add one. Once a command is saved, the game is marked installed.

4. SCRAPING & METADATA

CREMA can scrape metadata for individual games without going through CNGM. The scope matches CNGM’s Auto-Fetch: Cover, Hero Art, Logo, HLTB, ProtonDB, Description, Genre, Developer, Publisher, Co-op, Players, Metacritic, Screenshots.

How to Scrape

Navigate to a game in the gallery and press X / Square (or use the scrape option in the Game Menu). CREMA will:

  1. Search Steam for the game by name. If found, proceed with a full Steam + IGDB scrape.
  2. If Steam search finds nothing, CREMA offers an IGDB fallback — a search overlay where you can type the correct title and select from results.

IGDB Fallback

When the Steam search fails, a search overlay appears with IGDB results. Select the correct entry and CREMA fetches all available metadata. Especially useful for older games, non-English titles, or games not on Steam.

IGDB credentials required: The IGDB fallback requires a Twitch dev API key set in CNGM’s Connect menu. Without it, only Steam-based data is available.

5. MUSIC & ATMOSPHERE

CREMA has a built-in music player for ambient game-room atmosphere. It runs continuously while you browse and integrates seamlessly with the rest of the experience.

BGM Categories

CREMA ships with curated music organized into genre and mood categories. The default on first launch is Ambient. Switch categories in the Sound Settings overlay (Start button or the on-screen menu icon).

Sound Settings

  • Switch BGM category / style
  • Adjust BGM volume
  • Toggle BGM on or off
  • Adjust UI sound effects volume

Trailer Fade

When you play a trailer from the Gamepage, CREMA automatically fades out the BGM. When the trailer ends or you close the player, the BGM fades smoothly back in — seamless and cinematic.

Gaming History

CREMA maintains its own independent gaming history counter (separate from CNGM). Configure it in the Sound Settings menu: OFF, 5, 10, 15, or 20 most recently played games pinned to the top of the gallery.
