Cafe Neurotico Ecosystem

FAQ

Everything you need to know about CNGM, CREMA, and GRINDER — the Linux gaming ecosystem built for people who take their library seriously.

01
General & Ecosystem
What is the Cafe Neurotico ecosystem exactly?+

Three apps, one shared library, zero cloud dependency:

  • CNGM (Cafe Neurotico Game Manager) — the desktop library manager. Import games from Steam, GOG, Epic, and any other source. Scrape metadata, artwork, and trailers. Manage everything from a mouse and keyboard.
  • CREMA — the fullscreen, controller-first companion. Built for the couch. Features a Jukebox, cinematic screensavers, and seamless gamepad navigation.
  • GRINDER — the install and launch engine for GOG and Epic games. Handles downloading, Proton configuration, Wine prefix management, and compatibility files. Runs headlessly in the background when called from CNGM or CREMA.

All three apps share one GameManagerConfig folder. Place them in the same directory and they connect automatically.

Do I need all three apps?+

No. Each app is useful on its own:

  • Use CNGM alone if you just want a library manager with metadata, artwork, and store sync.
  • Use CREMA alone if you already know your games and want a pure couch interface with a Jukebox.
  • Use GRINDER alone if you want a dedicated GOG and Epic installer without the full library manager.

The three apps become more powerful together — CNGM shows GRINDER install status, CREMA can trigger installs via GRINDER — but none of them requires the others to be running.

Linux only? What about Windows or macOS?+

Linux only, and built specifically for it. The ecosystem relies on AppImage distribution, Linux shell launch commands, umu-run, Proton, and Wine. There are no plans for Windows or macOS ports.

Is my data sent to any server? Do I need an account?+

No accounts. No telemetry. No cloud. The entire ecosystem is offline-first and local-only. Your database, artwork, screenshots, and trailers all live inside the GameManagerConfig folder on your own drive. The only network calls the apps make are to APIs you explicitly trigger — Steam, IGDB, SteamGridDB — and only when you ask.

How do I move my library to a new machine?+

In CNGM: Tools → System → Backup ZIP. This packs your entire GameManagerConfig folder — database, all artwork, all downloaded trailers — into a single archive. Copy it to the new machine, run CNGM there, and use Restore ZIP. Your library is exactly as you left it. CREMA needs nothing extra — it reads the same restored folder.

After restoring, run Tools → System → Add to Application Menu to re-register all three apps in your desktop launcher with the correct paths.

GRINDER is handled separately. It is system-specific by design — game install paths, Wine prefixes, Proton versions, and store auth tokens are all tied to the machine they were configured on. On the new machine, reinstall GRINDER and run through its first-launch setup: authenticate with GOG and Epic, install and scan for GE-Proton, and set your default install directory. GRINDER will reconnect to your restored CNGM library automatically and let you reinstall your GOG and Epic games from scratch.

02 — CNGM
Game Manager
How do I import my Steam library?+

Open the Connect & Sync menu and enter your SteamID64 and a Steam Web API Key. Get your key at steamcommunity.com/dev/apikey and your SteamID64 from your profile URL or steamid.io.

One critical setting: your Steam profile's Game Details must be set to Public. If it is set to Private or Friends Only, the API returns nothing.

How do I import GOG and Epic Games libraries?+

Through GRINDER, the dedicated install engine. Place GRINDER.AppImage in the same folder as CNGM.AppImage, log in to your stores inside GRINDER (via the Sync GOG and Sync Epic buttons in GRINDER's sidebar), and CNGM reads GRINDER's database automatically on startup.

The Refresh button (⟳) in CNGM's sidebar forces an immediate sync with GRINDER if needed.

Can I track emulators, physical games, or apps?+

Yes. The Launch Command field accepts any terminal command — RetroArch, Ryujinx, RPCS3, a Flatpak, a shell script, anything you can run from a terminal. Set the category to Emulation, Physical, Others, or Apps and paste your command. Both CNGM and CREMA will launch it correctly.

Games in those categories without a Launch Command are treated as not installed, so they won't clutter the INSTALLED filter until you wire them up.

What is IGDB and do I need it?+

IGDB (Internet Game Database) is an optional metadata API. It provides a scraping fallback for games not on Steam, as well as franchise and series info. Get free credentials at dev.twitch.tv — register an app and copy your Client ID and Secret into CNGM's Connect & Sync menu.

Once set up, Auto-Fetch uses IGDB when Steam finds nothing, and CREMA's scraping menu offers an IGDB fallback for the same cases.

The scraper fetched the wrong artwork or metadata. How do I fix it?+

In CNGM: open Edit Details for the game and click Auto-Fetch again — if multiple Steam results are found, CNGM lets you pick from a list. You can also use the SGDB button next to any image field to browse and manually select exact artwork from SteamGridDB.

In CREMA: press X / Square on the game to open scraping options. Use Refine Search to type a more specific title via the on-screen keyboard, or switch to the IGDB fallback search if it's configured.

What is SteamGridDB and do I need an API key?+

SteamGridDB is a community database of custom game artwork — covers, hero images, logos, and icons. CNGM uses it when you click the SGDB button next to any image field. A free API key is required. Get one at steamgriddb.com/profile/preferences/api and save it in CNGM's Connect & Sync menu under SteamGridDB.

How does the INSTALLED filter work?+

The INSTALLED filter shows only games that are ready to play right now:

  • Steam games — detected by scanning your Steam library folders. A background watcher updates status the moment you install or uninstall something in Steam.
  • GOG and Epic games — synced from GRINDER's database. Use the ⟳ Refresh button to update.
  • Physical / Emulation / Others / Apps — considered installed only when a Launch Command is saved. No command = not installed.
03 — GRINDER
Install Engine
What does GRINDER actually do?+

GRINDER is the robot-barista of the ecosystem. It handles everything between you and a running game: authenticating with GOG and Epic, downloading game files, configuring Proton, creating Wine prefixes, installing compatibility files, and reading the game's official launch arguments so mods and add-ons load correctly — automatically.

It runs silently in the background when called from CNGM or CREMA, and has its own full UI when you open it directly.

Do I need to install GE-Proton separately?+

No external tool required. GRINDER has a built-in GE-Proton downloader: open Settings → Install GE-Proton, click Fetch Versions, pick a release, and click Install. GRINDER downloads the archive directly from GitHub and installs it to your compatibilitytools.d folder. After installing, it auto-scans so the new version appears in the Proton list immediately.

My GOG game launches but mods or expansions don't load.+

GOG games declare their exact launch configuration — including mod files, config paths, and arguments — in a goggame-*.info file inside the game folder. GRINDER reads this at launch time and applies those arguments automatically.

If something isn't loading, check the Launch Target dropdown in GRINDER's Edit screen. It lists all official launch options from the game's metadata. Make sure the option marked (default) is selected, or pick the one that includes the mods/expansion you need.

You can also use the Additional Arguments field to append extra flags on top of whatever the game declares.

What is the difference between Executable, Launch Target, and Additional Arguments?+
  • Executable — the game's main binary, relative to the install folder. Set automatically at install time. The permanent stored default.
  • Launch Target — a dropdown of all official launch options from the game's goggame-*.info file (e.g. Play, Editor, Mod Launcher). Overrides the Executable when set. GOG games only.
  • Additional Arguments — extra flags you type manually, appended after any arguments already declared in the playTask. Works for all stores. Example: -windowed, +set com_allowConsole 1.

For most games you never touch any of these — GRINDER handles everything automatically.

A GOG install fails or seems to do nothing. What do I check?+
  • GOG login — tokens expire. Click Sync GOG in the sidebar. If a Login button appears, authenticate and retry.
  • Disk space — GRINDER shows a pre-install size check. If space ran out mid-download, free some up and retry.
  • Platform — some games only ship a Windows build. If you chose Linux and it failed, try Windows (the game runs through Proton).
  • External Tools status — open Settings → External Tools. Check that gogdl and umu-run show as detected.
Can I manage multiple Proton versions and remove old ones?+

Yes. Settings → Proton Versions lists everything GRINDER finds across your system. You can set a default with one click and assign a different version per game in the Edit screen. GE-Proton versions installed via GRINDER (or placed in compatibilitytools.d) show a Delete button to remove them. Steam's official Proton versions are not deletable from GRINDER — manage those through Steam.

What are Winetricks and Run .exe on Prefix?+

Winetricks lets you install runtime components (Visual C++ Redistributables, DirectX, .NET, fonts) into a game's Wine prefix. Enter the component names space-separated in the Edit screen and click Run.

Run .exe on Prefix opens a file picker so you can run any installer, patcher, or tool inside the game's Wine prefix — mod installers that ship as .exe files, for example — using the same Proton and environment as the game itself.

04 — CREMA
Couch Companion
How do I get back to CREMA after closing a game?+

When a game launches, CREMA enters Sleep Mode — it yields resources to the game and fades the music. Once the game closes, press START + SELECT on your controller to wake CREMA and bring it back to the front.

On a keyboard: hold comma (,) and period (.) simultaneously. This always works regardless of which combo is configured.

You can change the wake-up combo in System Menu → Controls → Wake Method. Six options including hold variants to prevent accidental triggers.

Can I install games directly from CREMA?+

Yes. From CREMA's game menu (SELECT button on any uninstalled GOG or Epic game), choose Install via GRINDER. A gamepad-friendly confirmation dialog shows the install directory. Press A to confirm and GRINDER starts downloading in the background while CREMA stays fully usable in the foreground.

CREMA shows its own progress overlay — AUTH → DOWNLOAD → INSTALL → COMPAT steps with a live percentage bar — and updates the game's status automatically when done. The same works for uninstalling: Uninstall via GRINDER appears for installed GOG and Epic games.

How do I add my own music to the Jukebox?+

Place your audio files (MP3, WAV, OGG, FLAC) in the CREMA_CUSTOM_MUSIC folder in the same directory as CREMA.AppImage. Reopen the Jukebox from the System Menu — CREMA scans automatically and reads ID3 metadata (Title, Artist, Album, Cover Art). Browse by Artist, Album, or build custom Playlists inside the Jukebox.

To use custom music as background music while browsing, go to System Menu → Audio → Sound Settings and set the BGM style to Custom.

My controller isn't navigating CREMA. What's wrong?+

Make sure the CREMA window has system focus — click it once with your mouse if needed. CREMA uses the standard HTML5 Gamepad API, so Xbox, PlayStation, Switch Pro, and most generic PC controllers work natively without extra drivers. You can switch button icons between Xbox, PlayStation, and Nintendo layouts in System Menu → Controls → Gamepad Icons.

What are the screensavers and how do I configure them?+

CREMA has a screensaver that activates after a configurable idle period. It can show Cafe Neurotico wallpapers, screenshots from your game library, or be turned off entirely. While the screensaver is active, you can press A to launch the currently displayed game or B to return to the library.

Configure it in System Menu → Audio → Screensaver. Set the idle delay (1 to 30 minutes) and choose the content source.

05
Data & Backups
Where is all my data actually stored?+

Everything is in a single folder named GameManagerConfig, located in the same directory as your app files. Inside it: the SQLite database, downloaded cover art, hero images, logos, screenshots, and locally saved trailers. One folder, completely self-contained and portable.

GRINDER keeps its own database at ~/.config/grinder/grinder.db for game install records, and Wine prefixes at ~/.config/grinder/prefixes/.

How do I clean up disk space used by the image folder?+

CNGM has two cleanup tools in Tools → Cleanup:

  • Clean Images — deletes any image files in the folder that are no longer assigned to a game. Safe and surgical — nothing currently in use is touched.
  • Clear All Images — wipes all artwork and screenshots. Text metadata is preserved; visuals must be re-fetched afterwards.
Can I run the apps on a Steam Deck?+

Yes. The AppImages run on the Steam Deck in Desktop Mode. Place them in a folder on internal storage or an SD card. CREMA's controller-first design works particularly well on the Deck — the gamepad navigation was built with exactly this kind of device in mind.

Use CNGM's Tools → System → Add to Application Menu to register all three apps in KDE's application launcher so they appear in Game Mode as non-Steam entries.
