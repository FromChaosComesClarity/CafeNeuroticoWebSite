Frequently Asked Questions

Everything you need to know about CNGM, CREMA, and GRINDER — the Cafe Neurotico ecosystem for Linux gamers.

General & Ecosystem
Do I need to keep both CNGM and CREMA open at the same time?

No. They are standalone applications designed for different moments. They share the exact same GameManagerConfig folder and database. Use CNGM with your mouse and keyboard to organise your library, sync stores, scrape metadata, and manage media. When you want a fullscreen couch experience, close CNGM and open CREMA for your controller-based session — it also has a full music Jukebox built in.

You can also open the User Manual as a separate floating window alongside CNGM, so you can reference it while working in the app at the same time.

Does this work on Windows or macOS, or is it Linux only?

CNGM and CREMA are built as a labor of love for Linux, relying on AppImage distribution, shell launch commands, Heroic Games Launcher integration, and ProtonDB. Linux only, at least for now.

Is my data sent to a cloud server? Do I need to create an account?

Absolutely not. The entire ecosystem is 100% offline and local-first. All your data — cover art, screenshots, trailers, and the database — are stored in the GameManagerConfig folder on your own drive. No accounts, no subscriptions, zero telemetry.

What is the Welcome & Setup Guide?

The first time you launch CNGM (or any time you open a fresh GameManagerConfig folder), a Welcome & Setup Guide screen appears. It walks you through the five recommended setup steps — connecting stores, fetching artwork, setting up API keys, adding CREMA, and registering system shortcuts — with live action buttons built right into the panel. You can perform each step without closing the screen.

Check “Don’t show this again” if you no longer want it on startup. You can always reopen it from Tools → System → Show Welcome & Setup Guide.

Adding Games & Store Syncing
Why is my Steam library failing to import?

Make sure you have entered both your SteamID64 and a valid Steam Web API Key in the CNGM Connect menu. Most importantly, your Steam Profile’s Game Details privacy setting must be set to Public. If it is set to Private or Friends Only, the API returns nothing and the import will fail.

Get your API key at steamcommunity.com/dev/apikey and find your SteamID64 from your profile URL or at steamid.io.

Does this sync with Epic Games and GOG?

Yes — through GRINDER, the dedicated install and launch engine in the ecosystem. Place GRINDER.AppImage in the same folder as CNGM.AppImage, log in to GOG or Epic inside GRINDER, and import your library. CNGM reads GRINDER’s database automatically on startup and shows install status per game.

CNGM also supports importing via Heroic Games Launcher (Sync Heroic Games) as a secondary option, which additionally covers Amazon Games. If you already use Heroic, that sync still works. But for a self-contained workflow without Heroic, GRINDER is the recommended path for GOG and Epic.

Can I use this for emulators or physical games?

Yes. The Launch Command field accepts any terminal command. You can point it at RetroArch, Ryujinx, RPCS3, a Flatpak, a shell script — anything you can run from a terminal. CNGM and CREMA will launch it, and CREMA will enter Sleep Mode just like with a native game.

For physical or console games you just want to catalogue without a launch command, assign them to the Physical, Emulation, or Others category and leave the command blank. In CREMA, pressing Play on those games opens the on-screen keyboard so you can add a command on the spot.

What is IGDB and do I need it?

IGDB (Internet Game Database) is an optional but recommended API integration. It enriches your metadata with franchise / series info, additional ratings, and — crucially — provides a scraping fallback for games that aren’t on Steam or can’t be found by the Steam search.

To set it up, register a free Twitch developer app at dev.twitch.tv, copy your Client ID and Client Secret, and paste them into CNGM’s Connect menu. Once saved, Auto-Fetch pulls IGDB data automatically alongside Steam data, and both CNGM and CREMA can use the IGDB fallback search when Steam finds nothing.

How do I get a game into the INSTALLED category?

CNGM tracks installed status automatically:

  • Steam games are detected by scanning your Steam library folders for appmanifest_*.acf files. A live background watcher updates status the moment you install or uninstall something in Steam — no manual action required.
  • GOG and Epic games via GRINDER — CNGM reads GRINDER’s database on every startup and updates installed status automatically. Use the Refresh button (⟳) in CNGM's sidebar to force an immediate sync.
  • Heroic games (Epic, GOG, Amazon) — if you use Heroic, use Sync Heroic Games or Check Installed Games (Tools → Library) to refresh.
  • Physical / Emulation / Others / Apps are considered installed as soon as they have a Launch Command saved.

In both CNGM and CREMA, games not yet installed show an INSTALL button that opens the appropriate store page. The INSTALLED category filters your library to only show what’s ready to play right now.

CREMA & Controller Experience
I launched a game in CREMA. How do I get back to the CREMA interface?

When a game launches, CREMA enters Sleep Mode — it yields system resources to your game and fades out the background music. Once you close the game, wake CREMA by pressing START + SELECT simultaneously on your controller. CREMA forces itself back to the front and fades the music back in.

On a keyboard, hold comma (,) and period (.) simultaneously — this always works regardless of which wake combo is configured.

You can change the wake-up combo in the CREMA System Menu → Controls → Wake Method. Six options are available, including hold variants to prevent accidental triggers.

Steam or Heroic keeps popping up over CREMA after I close a game. How do I fix it?

Set your background launchers to hide on game launch. In Heroic: Settings → General → enable “Minimize Heroic on Game Launch” or “Hide to Tray”. CREMA’s wake-up combo actively forces itself over any lingering windows, which also helps bury stubborn launchers.

How do I add my own music to the CREMA Jukebox?

Place your audio files (MP3, WAV, OGG, or FLAC) in the CREMA_CUSTOM_MUSIC folder located in the same directory as the CREMA app. Close and reopen the Jukebox from the System Menu — CREMA scans the folder automatically and reads ID3 metadata (Title, Artist, Album, Cover Art). You can then browse by Artist, Album, or create custom Playlists inside the Jukebox.

To use your custom music as the background music while browsing, set the BGM style to Custom in System Menu → Audio → Sound Settings.

My controller isn’t navigating the CREMA menu. What’s wrong?

Make sure the CREMA window has system focus — click it once with your mouse if needed. CREMA uses the standard HTML5 Gamepad API, so almost any Xbox, PlayStation, Switch Pro, or generic PC controller works natively without extra drivers. You can switch the displayed button icons between Xbox, PlayStation, and Nintendo layouts in System Menu → Controls → Gamepad Icons.

Data Management & Backups
Where are all my covers, trailers, and data actually stored?

Everything lives in a single folder named GameManagerConfig in the exact same directory as your CNGM and CREMA app files. Inside it: the SQLite database (game_library.db), your downloaded cover art, hero images, logos, screenshots, and locally downloaded MP4 trailers. One folder, fully self-contained and portable.

How do I move my library to a new PC or Steam Deck?

In CNGM, open Tools → System → Backup ZIP. This compresses your entire GameManagerConfig folder — database, all artwork, all trailers — into a single archive. Copy it to your new machine, run CNGM there, and use Restore ZIP. Your library will be exactly as you left it, including all covers and downloaded trailers.

After restoring on a new machine, run Tools → System → Add to Application Menu to re-register CNGM and CREMA in your desktop launcher with updated paths.

Why did the scraper grab the wrong cover art or metadata for my game?

The Steam scraper searches by text, so sequels, remasters, or games with similar names can sometimes overlap. In CNGM, open Edit Details for that game, click 🧹 Clear Meta to wipe the scraped data, then click ✨ Auto-Fetch again — if multiple Steam results are found, CNGM will show you a list to pick from. You can also use the SGDB button next to any image field to browse and pick exact custom artwork from SteamGridDB.

In CREMA, press X / Square on the game to open scraping options. If Steam finds the wrong game or nothing at all, choose Refine Search to type a more specific title via the on-screen keyboard, or use the IGDB fallback to search IGDB directly if it’s configured.

My image folder is getting large. How do I clean it up?

CNGM has two cleanup tools in Tools → Cleanup:

  • Clean Images — scans your database and deletes any image files in the images/ folder that are no longer assigned to a game. Safe and surgical — nothing currently in use is touched. Run this whenever you’ve swapped a lot of covers or logos.
  • Clear All Images — the nuclear option. Wipes all downloaded artwork and screenshots. Your text metadata is preserved, but all visuals must be re-fetched.
GRINDER — GOG & Epic Install Engine
What exactly is GRINDER and do I need it?

GRINDER is the dedicated install and launch engine for GOG and Epic games in the Cafe Neurotico ecosystem. It handles downloading, Proton configuration, Wine prefix management, compatibility file installation, and launching — all in one place, without Heroic Games Launcher.

You need it if you want to install GOG or Epic games from within the ecosystem. If you only play Steam games or already use Heroic for launching, GRINDER is optional — CNGM and CREMA work fine without it. But if you want a fully self-contained workflow, GRINDER is the recommended path.

My GOG game launches but the mods / expansions don't load. What's wrong?

This is the most common GRINDER question. GOG games declare their exact launch configuration — including which mod files and config paths to load — inside a goggame-*.info file in the game folder. GRINDER reads this at launch time and applies those arguments automatically.

If the game was working in Heroic but not in GRINDER, the likely causes are:

  • The Launch Target in GRINDER's Edit screen is set to a different option than the one that loads the mods. Check the dropdown and select the entry marked (default).
  • The game's goggame-*.info file is absent or was not downloaded (rare, usually a corrupted install).

You can also use the Additional Arguments field in the Edit screen to manually append any flags the game needs.

How do I install GE-Proton without ProtonUp-Qt?

GRINDER has a built-in GE-Proton downloader. Open GRINDER → Settings → Install GE-Proton. Click Fetch Versions to load the latest 15 releases from GitHub, pick a version, and click Install Selected Version. GRINDER downloads the archive, extracts it to ~/.steam/root/compatibilitytools.d/, and updates the Proton scanner automatically.

ProtonUp-Qt is no longer needed for GE-Proton management if you use GRINDER.

Can CREMA install games while I'm gaming on the couch?

Yes. This is one of GRINDER's most useful features. From CREMA's game menu (SELECT button), uninstalled GOG and Epic games show an Install via GRINDER option. GRINDER runs completely headlessly in the background while CREMA stays in the foreground, displaying its own progress overlay with AUTH → DOWNLOAD → INSTALL → COMPAT steps and a live percentage bar. You never leave the couch interface.

The same works for uninstalling: Uninstall via GRINDER appears in the game menu for installed GOG and Epic titles.

What's the difference between Executable, Launch Target, and Additional Arguments?

All three live in GRINDER's Edit screen and affect what gets run when you click Play:

  • Executable — The path to the game's main binary, relative to the install folder. Set automatically at install time. This is the permanent stored default.
  • Launch Target — A dropdown populated from the game's official goggame-*.info playTasks. Lets you switch between declared options like "Play", "Editor", or "Mod Launcher" without touching the Executable field. When set, it overrides the Executable. GOG games only.
  • Additional Arguments — Extra flags you type in manually, appended after any arguments already declared in the playTask. For example: -windowed, +set com_allowConsole 1. Applies to all stores.

For most games, you never touch any of these — GRINDER handles everything automatically. They exist for power users who need to fine-tune the launch.

Do I still need Heroic Games Launcher?

For GOG and Epic games: no, not if you use GRINDER. GRINDER handles everything Heroic did for those stores — authentication, downloading, Proton configuration, and launching.

For Amazon Games: yes, Heroic is still the only way to play Amazon Games on Linux. CNGM can sync your Amazon library from Heroic.

If you already have games installed via Heroic, you don’t need to reinstall them. CNGM can import them via Sync Heroic Games and launch them through Heroic as before. GRINDER is for new installs or if you want a fully self-contained workflow without Heroic.

A GOG game fails to install with no error, or completes but shows as not installed.

A few things to check:

  • Log in again — GOG tokens expire. Click Sync GOG in the GRINDER sidebar. If you are shown a Login button, authenticate and retry the install.
  • Check disk space — GRINDER shows a pre-install size check. If it ran anyway and space ran out mid-download, the install will fail silently. Free up space and retry.
  • Linux vs. Windows platform — Some games only have a Windows build and no Linux native build. If you selected Linux and it failed, try Windows (the game will run through Proton).
  • gogdl binary — Check Settings → External Tools to confirm gogdl is detected.
