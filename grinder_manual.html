CAFE NEUROTICO: GRINDER

1. THE ROBOT-BARISTA

THE ENGINE ROOM

GRINDER is the install and launch engine of the Cafe Neurotico ecosystem. While CNGM manages your entire library and CREMA provides the couch-friendly interface, GRINDER does the actual work — it grinds the beans.

It is dedicated exclusively to GOG and Epic Games on Linux. It handles everything from the first authentication to the final executable: downloading, installing, configuring Proton, managing Wine prefixes, installing compatibility files, and reading each game's official launch arguments so mods and expansions load correctly without any manual setup.

MECHANICAL PRECISION

GRINDER was built on one principle: zero shortcuts. It reads the game publisher's own declared launch configuration (via GOG's goggame-*.info playTasks) and applies it exactly. If Ashes 2063 declares it needs five mod files and a custom config loaded at startup, GRINDER reads that and does it. You just click Play.

It is fully integrated with CNGM (which tracks install status and opens GRINDER on demand) and CREMA (which can trigger installs and uninstalls headlessly, showing its own progress UI while GRINDER runs silently in the background).

2. REQUIREMENTS

Bundled (no install needed)

  • legendary — Epic Games library management and installation. Bundled inside the AppImage.
  • gogdl (Cafe Neurotico fork) — GOG library management and installation. Bundled inside the AppImage.

Strongly Recommended

  • umu-run — The preferred launch method for Windows games. Handles Proton invocation correctly and is required for the best compatibility. Install via:
    pipx install umu-launcher
    Or use the one-click installer in GRINDER's Settings → External Tools.
  • GE-Proton — The recommended Proton build for gaming. Install directly from GRINDER's Settings → Install GE-Proton — no external tools required.

Optional

  • wine — Only used as a last resort if no Proton version is configured and umu-run is absent. Not needed in a typical setup.
  • winetricks — Required if you want to install runtime components (Visual C++ Redistributables, DirectX, etc.) into a game's Wine prefix from within GRINDER.

Tip: Open GRINDER's Settings tab to see the live status of all tools. It will tell you exactly what is found, what is bundled, and what needs attention.

3. QUICK START

First Launch

On first launch, GRINDER shows a Welcome Screen with a live tool check and Getting Started steps. It tells you what is installed, what is missing, and what to do next. Once you've reviewed it, check Don't show this again and click LET'S GO. You can always reopen it from Settings → About → Show Welcome Screen.

Placement

Place GRINDER.AppImage in the same folder as CNGM.AppImage. They connect automatically — CNGM reads GRINDER's database at startup with no configuration required.

Recommended First-Run Workflow

  1. Open Settings → Install GE-Proton. Fetch the latest version and install it.
  2. Open Settings → Proton Versions. Click Scan, then set the newly installed GE-Proton as default.
  3. Open Settings → Default Prefix Directory. Leave blank for the default or set a custom path.
  4. Click Sync GOG or Sync Epic in the sidebar to import your library.
  5. Select a game and click Install.

4. IMPORTING GAMES

GOG

Click Sync GOG in the sidebar. If you are not logged in, the import dialog will show a Login to GOG button. GRINDER opens a secure GOG authentication window — log in, close it when done, and GRINDER stores your tokens locally. Your full GOG library appears immediately.

Select all the games you want to track (all are pre-selected by default) and click Import Selected. Only your own library is imported — ratings, reviews, and store metadata are not fetched at this stage.

Tip: You only need to log in once. GRINDER refreshes your tokens automatically. If a token expires, clicking Sync GOG again will prompt you to re-authenticate.

Epic Games

Click Sync Epic in the sidebar. If not logged in, click Login to Epic Games. GRINDER opens a legendary authentication flow in a terminal-style output window. Follow the on-screen instructions (you will be asked to open a URL and paste a code). Once authenticated, your Epic library loads.

What Gets Imported

GRINDER imports the game title, store identifier, and install status. If a game is already installed on disk (from a previous GRINDER or Heroic install), GRINDER detects it and marks it accordingly. Uninstalled games show an Install button.

5. INSTALLING GAMES

Starting an Install

Select a game in the library list. The right panel shows its details. Click Install. For GOG games, a platform dialog appears first.

Platform Selection (GOG only)

Many GOG games ship both a Windows and a Linux native build. GRINDER asks which you want:

  • Linux — A native build that runs directly without Proton. Best performance, but not all games have a Linux build.
  • Windows — Runs through Proton/Wine. Required for Windows-only titles and usually necessary for mod support.

Tip: When in doubt, choose Windows. Even games with Linux builds often have better mod and DLC support on the Windows version via Proton.

Pre-Install Size Check

GRINDER checks download size, unpacked size, and available disk space before starting. If there is not enough space, the Install button is disabled with a warning.

Install Directory

The default install directory is ~/Games/CafeNeurotico/. You can change it per-install in the dialog, or set a global default in Settings → Launch Engine → Default Prefix Directory.

Progress

A progress panel shows real-time output from gogdl or legendary: percentage, bytes transferred, and the current file being written. You can cancel at any time.

Automatic Compatibility Files (GOG)

Immediately after a successful GOG install, GRINDER checks the game's declared dependencies and installs any required compatibility files (Visual C++ Redistributables, DirectX, etc.) through umu-run/Proton. This happens automatically without any user action required.

Uninstalling

Click Uninstall in the game's right panel. GRINDER removes:

  • The game files from disk.
  • The game's Wine prefix.
  • The store's install record (legendary or gogdl manifest).

Warning: Uninstall is permanent. Save files stored inside the Wine prefix will also be removed. Back up your saves first if needed.

6. LAUNCHING GAMES

Launch Chain

When you click Play, GRINDER runs through this priority chain to find the best available runner:

PriorityRunnerWhen Used
1umu-run + Protonumu-run is installed and a Proton path is set
2Proton directProton path is set but umu-run is absent
3WineLast resort — no Proton configured
—Native binaryLinux-native GOG games (no Proton involved)

Official Launch Arguments (GOG)

GOG games declare their exact launch configuration in a goggame-*.info file inside the game folder. This file contains playTasks — the official list of launch options with executable paths and arguments. GRINDER reads this file at launch time and applies the arguments exactly as the publisher declared them.

This is what makes mods, expansions, and custom configs work without any manual setup. For example, Ashes 2063 declares five mod files and a config path that must be passed to GZDoom — GRINDER reads that and does it automatically.

Launch Target

Some games declare multiple play options in their playTasks: Play, Editor, Mod Launcher, Addon, etc. The Launch Target dropdown in the Edit screen lets you switch between them without touching the Executable field. The option marked (default) is what GOG considers the primary launch target.

Additional Arguments

The Additional Arguments field in the Edit screen lets you append your own flags to any game launch. These are added after the official playTask arguments, so mods and configs still load first.

Examples: -windowed, +set com_allowConsole 1, --skip-intro, --fps-cap 60.

Quoted arguments with spaces are supported: -cfg "/path with spaces/my.cfg".

Tip: If you want to completely override the official launch arguments (instead of appending), clear the Launch Target dropdown and write everything you need in the Additional Arguments field.

.bat File Support

Some GOG games use Windows batch files as their primary launcher. GRINDER detects .bat extensions automatically and converts the path to Wine's Z: drive format, which Wine routes through its internal cmd.exe. No manual workaround is needed.

Working Directory

All game spawns set the working directory to the game's install folder. This means relative paths in arguments and batch files resolve correctly without requiring absolute paths.

7. PER-GAME SETTINGS

Open the Edit screen for any game (pencil icon or double-click) to access its per-game configuration.

Core Fields

FieldPurpose
ExecutablePath to the game's main binary, relative to the install folder. Set automatically at install time from the primary playTask. Can be changed manually.
Additional ArgumentsExtra flags appended to the launch command after official playTask arguments.
Launch TargetDropdown of all declared play options from goggame-*.info. Overrides the Executable when set. GOG games only.
Install PathWhere the game files live on disk.
Wine PrefixPath to the game's Wine prefix. Defaults to ~/.config/grinder/prefixes/<Game Title>/.
Proton VersionPer-game Proton override. Overrides the system default for this game only.
NotesPersonal notes. Not used at launch.

Environment Variables

The Environment Variables textarea accepts KEY=value pairs, one per line. These are applied at launch before any Proton or Wine environment. Useful for game-specific overrides like DXVK_LOG_LEVEL=none or __GL_SHADER_DISK_CACHE=1.

Compatibility Toggles

ToggleWhat It Does
EsyncEvent-based synchronisation for better multi-thread performance. On by default.
FsyncFutex-based synchronisation. Faster than Esync on supported kernels. On by default.
DXVK-NVAPINVIDIA API emulation layer. Enable for games that use DLSS or NVIDIA-specific features on GE-Proton.
BattlEyeSets the BattlEye runtime path for anti-cheat protected games. GRINDER detects it automatically if it is already present in your Steam library — it gets installed by Steam when you first install any Steam game that uses BattlEye. If you have never done that, the toggle has no effect.
EACSame as BattlEye but for Easy Anti-Cheat — present if you have installed a Steam game that uses EAC.

8. PROTON MANAGEMENT

Proton Scanner

Open Settings → Proton Versions and click Scan Proton Versions. GRINDER searches all standard locations:

  • ~/.steam/root/compatibilitytools.d/
  • ~/.local/share/Steam/compatibilitytools.d/
  • ~/.local/share/Steam/steamapps/common/ (Steam's official Proton)
  • Flatpak Steam equivalents under ~/.var/app/com.valvesoftware.Steam/

Symlinks are resolved to avoid duplicates. Each found version is listed with its type and full path. Click Set Default next to any version to use it globally.

GE-Proton Downloader

Settings → Install GE-Proton lets you download and install GE-Proton directly from the GloriousEggroll GitHub releases — no ProtonUp-Qt required.

  1. Click Fetch Versions to load the latest 15 releases (tag, date, download size).
  2. Pick a version from the dropdown.
  3. Click Install Selected Version. A progress bar tracks the download in MB.
  4. GRINDER extracts the archive to the first available compatibilitytools.d and auto-rescans the Proton list.

You can cancel at any time. The partially downloaded archive is cleaned up automatically.

Tip: Always use the latest GE-Proton for best game compatibility. It includes upstream fixes from Valve's Proton plus community patches not yet in the official build.

Uninstalling Proton Versions

In the Proton Versions list, any version installed inside compatibilitytools.d (GE-Proton and other custom builds) shows a Delete button. Click it to permanently remove that version from disk.

Warning: If the version you delete is set as the default, GRINDER will warn you and clear the default setting. You will need to set a different Proton version before launching any Windows game.

Valve's official Proton versions (inside steamapps/common/) do not show a Delete button — those are managed by Steam.

9. COMPATIBILITY TOOLS

Winetricks

The Winetricks section in the Edit screen lets you install runtime components into a game's Wine prefix — Visual C++ Redistributables, DirectX, .NET, fonts, and hundreds of other packages that Windows games depend on.

  • Enter the component names space-separated: vcrun2019 d3dcompiler_47 dotnet48
  • Click Run Winetricks. A progress output shows the installation log.
  • Components are saved to the game record so you remember what was installed.

Tip: winetricks must be installed on your system. Install it via your package manager: sudo dnf install winetricks / sudo apt install winetricks.

Run .exe on Prefix

The Run .exe on Prefix button opens a file picker where you can select any .exe, .msi, or .bat file to run inside the game's Wine prefix using the same Proton and environment settings as the game itself. Use this for:

  • Mod installers that ship as .exe files.
  • Patchers and launchers that must run in the game's prefix.
  • DirectX or Visual C++ redistributables that winetricks doesn't cover.

Install Compatibility Files

The Install Compat. Files button in the Edit screen manually triggers the GOG redistributable installer for that game. This is the same process that runs automatically after a fresh install — useful if it was skipped or failed the first time.

GRINDER downloads the declared dependencies via gogdl, then runs each installer through umu-run/Proton with GAMEID=umu-0 so they install correctly into the game's prefix.

umu-run Installer

If umu-run is not found on your system, Settings → External Tools shows an Install umu-run button. It runs pipx install umu-launcher (or pip install --user if pipx is unavailable) and shows the output live. Works on any distro.

10. CNGM & CREMA INTEGRATION

Auto-Detection

Place GRINDER.AppImage in the same folder as CNGM.AppImage. CNGM detects GRINDER at startup by scanning for the file and reads GRINDER's database directly. No configuration, no pairing steps, no shared secrets.

What CNGM Gets From GRINDER

  • Per-game install status (installed / not installed), synced on every CNGM startup.
  • INSTALL button in CNGM's library now opens GRINDER with the game name pre-filled in the search bar, for GOG and Epic games.
  • A GRINDER button in the game detail page hero area opens GRINDER pre-searched to that game.
  • Theme sync — GRINDER reads CNGM's active colour theme at startup and applies it before the window appears.

CREMA Headless Mode

CREMA (the fullscreen gamepad companion) can trigger GRINDER installs and uninstalls without GRINDER's window ever appearing. GRINDER runs silently in the background and writes live progress to a shared JSON file that CREMA reads to power its own progress overlay.

From CREMA's game menu (Select button), GOG and Epic games show:

  • Install via GRINDER — shows a gamepad-friendly confirmation dialog with the install directory, then starts the download.
  • Uninstall via GRINDER — confirms, then removes files and the Wine prefix.

CREMA's progress overlay shows AUTH → DOWNLOAD → INSTALL → COMPAT steps with a live percentage bar. The entire process is controlled from the couch, with no keyboard or mouse required.

CLI Arguments

External callers (CNGM, CREMA, scripts) can control GRINDER via command-line arguments:

CommandAction
GRINDER.AppImage launch <id>Launch a game headlessly by its GRINDER ID.
GRINDER.AppImage search <name>Open GRINDER with the search box pre-filled.
GRINDER.AppImage setup <id>Open the Edit modal for a specific game.
GRINDER.AppImage install <store> <id> [dir]Headless install (used by CREMA). Store: gog or epic.
GRINDER.AppImage uninstall-headless <store> <id>Headless uninstall (used by CREMA).

11. SETTINGS REFERENCE

Launch Engine

  • Default Proton Path — The Proton version used for all games that don't have a per-game override. Set this after scanning your Proton versions.
  • Default Prefix Directory — Where Wine prefixes are created. Each game gets its own subfolder named after its title. Defaults to ~/.config/grinder/prefixes/.

Epic Games (Legendary)

Shows your login status. Login and Logout buttons appear as appropriate. legendary is bundled with GRINDER — no separate install is needed.

GOG

Shows your login status. Login and Logout buttons appear as appropriate.

Install GE-Proton

Downloads GE-Proton releases directly from GitHub. See Section 8 for the full workflow.

Proton Versions

Lists all detected Proton versions with type (GE-Proton, Steam Proton, etc.) and path. Scan to update the list. Set Default and Delete buttons per version. See Section 8.

External Tools

Live status of legendary, gogdl, umu-run, and wine. Shows whether each is bundled, a system install, or not found. Includes the one-click umu-run installer when umu-run is absent.

About

Show Welcome Screen — Reopens the first-launch guide with live tool status. The welcome screen also resets for next launch.
