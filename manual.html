CAFE NEUROTICO GAME MANAGER

1. MANIFESTO & PHILOSOPHY

YOUR LIBRARY. MANAGEABLE. SEARCHABLE. PORTABLE.

I wanted an app that could organize and launch all my games — from Steam, Heroic (Epic and GOG), Flatpak, Emulators, or whatever — in just one place.

I wanted it to be complete with all the features I've always wished I had in a Linux game manager: checking YouTube videos, HowLongToBeat, and ProtonDB right from inside the app, among other things.

I wanted it to be simple, beautiful and themeable.

And most importantly, I wanted it to be completely PORTABLE and BACKUPABLE.

THE LOCAL-ONLY PHILOSOPHY

CNGM is built with a strict Offline-First, Local-Only philosophy for your media. Once you fetch artwork, covers, logos, or download a trailer, it is saved securely into your local GameManagerConfig folder.

This means your library will never suffer from “link rot” or broken web images if a storefront changes its API. It also means you can pack up the entire folder, put it on a thumb drive, and take your flawlessly curated library to another PC entirely.

THE LAUNCH COMMAND

The crucial feature. Inside the Edit Details screen, there is a field where you can put a command to launch any game. Anything goes — if you can run it on Linux, you can run it from here.

If you imported your games via Steam or Heroic Sync, the launch commands are filled in automatically, even if the game is not installed. Clicking PLAY will prompt you to install it.

2. QUICK START

CNGM and CREMA are two apps that share one library database and live in the same folder. Neither requires system installation — just run the AppImage.

The Welcome & Setup Guide

Every time CNGM launches, it shows a Welcome & Setup Guide screen that walks you through the recommended first-run workflow step by step. Each step has live action buttons built right into the panel — you can sync Heroic, enter your Steam credentials, run a batch fetch, save API keys, and register shortcuts all without leaving the screen.

Tip: The Welcome Screen shows on every launch by default. Check “Don’t show this again” to stop it. You can always reopen it from Tools → System → Show Welcome & Setup Guide.

Your Files

On first launch, CNGM creates a GameManagerConfig folder next to the app:

  • game_library.db — your SQLite library (all games and metadata)
  • images/ — covers, hero art, logos, icons, screenshots
  • trailers/ — locally downloaded MP4 trailers

Portability: Back up the entire GameManagerConfig folder and you have your complete library. Restore it anywhere and it works immediately.

Recommended First-Run Workflow

  1. On first launch, the Welcome & Setup Guide appears — follow its steps for the fastest setup.
  2. Open Connect and sync your stores — Heroic first, then Steam.
  3. Open Tools → Library and run Batch Fetch Missing Data to pull artwork for all synced games at once.
  4. Set up SteamGridDB (free key at steamgriddb.com) and IGDB (free Twitch dev key at dev.twitch.tv) in the Connect menu.
  5. Place CREMA.AppImage in the same folder as CNGM to activate the fullscreen companion.
  6. Open Tools → System → Add to Application Menu to register both apps in your desktop launcher — no terminal required.

3. ADDING GAMES & STORE SYNC

Click Connect in the sidebar. All data is stored locally — no cloud accounts required.

Heroic Sync (Epic / GOG / Amazon) — Recommended

CNGM reads Heroic’s local config files directly — no login, no API key. It imports everything you own, installed or not, with the correct native launch commands already filled in. Amazon Games are also included if connected in Heroic.

Steam API Import

Get a free API Key at steamcommunity.com/dev/apikey and find your 17-digit SteamID64 at steamid.io. Enter both in the Connect menu.

Important: Your Steam profile’s Game Details must be set to Public for the API to return your library.

IGDB Integration

Get free credentials at dev.twitch.tv — register a Twitch developer app and copy the Client ID and Secret into the Connect menu. Auto-Fetch then pulls IGDB data (franchise info, ratings, co-op data) alongside Steam data.

GOG Direct Login

Opens a secure internal browser. Log in and close it — CNGM imports your owned GOG titles. This method cannot auto-generate launch commands, so connecting GOG to Heroic and using Heroic Sync is strongly recommended instead.

Adding Games Manually

Hit + Add Game, enter the title, then use ✨ Auto-Fetch in Edit Details to pull all metadata and artwork automatically. For Physical, Emulation, or other non-store games, type any terminal command in the Launch Command field.

Advanced: Custom Stores & Tags

The Store field is plain text with no restrictions — you can type anything you want there. This opens up a neat trick: create your own virtual stores for platforms that don’t have a dedicated sidebar button, like itch.io, GeForce Now, Xbox Cloud Gaming, Humble Bundle, GamePass, or anything else.

The search bar searches every field in the database, including Store. So a game with Store: itch.io will appear when you type itch.io in the search box, giving you instant filtered access to all your itch.io games.

Recommended pattern: Use Others, itch.io instead of just itch.io. The comma-separated value means the game still shows under the Others sidebar filter (which matches anything containing the word “others”), and is also searchable by typing itch.io. Using just the custom name alone works fine too — it will be searchable but won’t appear under any sidebar filter button.

Avoid accidental keyword matches: Don’t include steam, epic, gog, heroic, amazon, physical, others, emulation, or apps unintentionally in a custom name — the sidebar filters use a simple text match, so a store named steam-like would show up under the Steam filter.

4. VIEWS & NAVIGATION

Three main views share one persistent sidebar. Clicking a sidebar filter from anywhere — even deep inside a Gamepage — snaps you back to the last grid view and applies the filter instantly.

The List View

High-density, spreadsheet-style. Shows launch status, Favs, Want to Play, Store, Genre, and Release Year. Double-click any row to open its Gamepage. Recently played games pin to the top when Gaming History is enabled.

The Gallery View

Cover-art grid with a dynamic Hero header at the top that cycles through hero art and screenshots from your current filter using a Ken Burns zoom and crossfade — a built-in animated screensaver. Each card shows the cover, store badge, and an install status dot.

Sidebar Filters

  • All Games / Installed / Favs / Want
  • Steam / Epic / GOG / Amazon — by store
  • Physical / Others / Emulation / Apps — manual categories

The CREMA Button

If CREMA.AppImage is in the same folder, a Go Fullscreen With CREMA button appears at the bottom of the sidebar. Clicking it minimizes CNGM and launches CREMA. Both apps share the same database — changes in one are visible in the other immediately.

5. INSTALLED STATUS

CNGM tracks whether each game is currently installed and shows it everywhere in the UI.

The Install Dot

A small dot overlays each cover card and list row. Green = installed. Orange = not installed or unknown.

How Detection Works

  • Steam: Scans appmanifest_*.acf files across all Steam library folders (including secondary drives). A live file watcher updates status automatically when you install or uninstall in Steam.
  • Heroic (Epic / GOG / Amazon): Reads Heroic’s installed.json. Refresh with Sync Heroic or Check Installed Games.
  • Physical / Others / Emulation / Apps: Considered installed only if a Launch Command is saved. Adding the command marks it installed immediately.

Install / Play Buttons

Uninstalled games show an INSTALL button in Gallery and List view. For Steam/Heroic it opens the relevant store install page. For manual categories it opens the Add Command dialog.

Check Installed Games in Tools → Library rescans your entire library at once. Use it after a Heroic library update.

6. THE GAMEPAGE

Double-click any entry to open the immersive Gamepage — a premium storefront-style view for that game.

What You See

  • Hero Banner: Full-width cropped image with the transparent Logo overlaid at center.
  • Action Bar: Play / Install, Edit Details, Watch Trailer (if downloaded), FAV toggle, WANT TO PLAY toggle.
  • Stats Panel: Release year, Developer, Publisher, Genre, HLTB, Metacritic, ProtonDB, Co-op, Players, Franchise, Similar Games.
  • Description: Plain-text summary followed by the full rich HTML Steam store description.
  • Screenshots: Ken Burns animated slideshow. Click to see a gallery with full screenshots.

CRAFTING THE ULTIMATE GAMEPAGE

  1. Auto-Fetch first — covers ~90% of everything in one click.
  2. Click SGDB next to Hero Art or Logo to browse stunning fan-made custom art.
  3. Click ▶ WATCH TRAILER in the edit bar, search YouTube, pick the best result, and download it locally.
  4. Save and return — fully curated, completely offline, beautiful.

7. EDIT DETAILS & AUTO-FETCH

Click ⚙️ EDIT DETAILS from any Gamepage. Every field is editable and saves directly to the database.

✨ Auto-Fetch

The single most powerful button. One click pulls: Cover, Hero Art, Logo (with SGDB fallback), Icon, up to 5 Screenshots, Description, Release Year, Developer, Publisher, Genre, Franchise, HLTB, ProtonDB, Metacritic, Co-op, Players.

HLTB & ProtonDB Live Lookups

The 🔍 icons next to HLTB and ProtonDB fields trigger live API queries. If the lookup fails (unusual title, API down), CNGM opens a secure internal browser directly to the search results page — read the value, close the window, type it in. No dead ends.

Asset Management

Each image asset (Cover, Hero, Logo, Icon) has four options: Auto (Steam CDN), SGDB (community art), Local (pick a file), and Delete.

🧹 Clear Meta

Wipes all scraped text fields without touching images or launch commands. Use to re-scrape a game completely from scratch.

8. MEDIA, SGDB & TRAILERS

SteamGridDB (SGDB)

Get a free API key at steamgriddb.com and paste it into the Connect menu. Every SGDB button in the Edit screen opens a browsable grid of top-rated community art for that asset type. If the auto-search picks the wrong game, use the manual search box inside the SGDB window to hunt for the exact variation. Click an image to apply it immediately.

YouTube Trailers & The Local Rule

Click ▶ WATCH TRAILER in the edit bar to search YouTube. CNGM uses yt-dlp to download the highest-quality MP4 to your local trailers/ folder.

The Local Rule: The 🎬 WATCH TRAILER button on the Gamepage only appears if the trailer has been downloaded to disk. CNGM never streams from the internet on the Gamepage. If the button is there, the video plays instantly, offline, at maximum quality.

yt-dlp and ffmpeg are bundled inside CNGM — no extra installation required. Trailer downloads work out of the box.

9. TOOLS & SETTINGS

Click Tools in the sidebar. Use the search bar at the top to jump directly to any setting by keyword.

🎨 Appearance

Theme Selection opens the full theme picker — live-preview any color scheme instantly without committing. UI Scale zooms the interface from 50% to 150%, useful for Steam Deck or 4K displays.

Themes are organised into categories. Use the dropdown on this very page to preview them all live:

  • Originals & System — the core set: Dark Gray, CREMA, Cyberpunk, Snow, MoviesFlix, Vapour OS, PSIV Blue, Green Box, Win XP.
  • Aesthetics — mood-driven originals: Earthy & Organic, Dopamine Brights, Retro Revival, Vaporwave, Aurora, Noir, Bioluminescence, Brutalist.
  • Linux Ricing — popular terminal colour schemes: Dracula, Gruvbox, Nord, Solarized Dark, all four Catppuccin flavours (Latte, Frappé, Macchiato, Mocha), Tokyo Night, Everforest, Rosé Pine, Oxocarbon, Material Dark.
  • Sci-Fi Universes — themed after iconic sci-fi worlds: N7, Tron Legacy, Dead Space, Colony Ship, Necromorph.
  • Horror Realm — dark and unsettling atmospheres: Crimson Peak, Lakeside Curse, The Backrooms.
  • Gaming Legends — console nostalgia: Game Boy DMG, Pip-Boy, Sevastopol, Rip and Tear Classic, Super Brothers, Green Hill, NES, SNES.
  • PSIII Colors — seven monochrome variants of the Classic PSIII palette: Classic, Red, Green, Blue, Purple, Gold, Silver.

🕒 Gaming History

Controls how many recently launched games pin to the top (OFF, 5, 10, 15, or 20). Clear History wipes timestamps without touching other data. CNGM and CREMA maintain separate history counts.

✨ Library

  • Refresh Heroic New Games: Opens Heroic, watches for library changes, auto-syncs when Heroic finishes. Use after buying a new game.
  • Batch Fetch Missing Data: Scans all five asset types for every game and silently pulls whatever is missing from Steam.
  • Check Installed Games: Rescans Steam appmanifests and Heroic files, updating installed status for your entire library.
  • Export / Import CSV: Move your library in and out of spreadsheet format. CSV Template downloads a blank sheet with all correct column headers.

🗄️ System

  • Backup ZIP: Packs your entire GameManagerConfig folder into a single archive — your complete migration package.
  • Restore ZIP: Unpacks a backup. Warning: overwrites your current library entirely.
  • Add to Application Menu: Registers both CNGM and CREMA in your desktop launcher (GNOME, KDE, XFCE…) with icons. No terminal required. Re-run if you move the folder.
  • Show Welcome & Setup Guide: Reopens the first-run setup screen. Also resets the “don’t show again” flag for next launch.

🧹 Cleanup

  • Clean Images: Deletes orphaned image files no longer assigned to any game. Safe and surgical.
  • Clear All Images: Wipes all downloaded artwork and screenshots. Text metadata is preserved; all visual assets must be re-fetched.
  • Wipe Secure Browser Data: Clears the internal Chromium cache used by the GOG login window. First thing to try if a store sync is behaving strangely.
